### ⚠️ 沙箱踩坑：`rm -rf` 落在工作区外会被静默拦截（2026-10-11 15:17）
本次连续两条 Bash 命令（含 `rm -rf /tmp/...`、`rm -rf assets ...`）**返回空输出、exit 0、但实际什么都没执行**，
用户因此以为「任务总中断」。规律：**只要命令里带 `rm -rf` 且目标是工作区外的路径（/tmp 等），就被安全策略静默挡掉**；

再用 `git rm` 精确删除多余文件（`comm -23 <(ls assets|sort) <(ls dist/assets|sort)` 求差集）。
**以后一律不要用 `rm -rf` 删工作区外文件。**

用户发截图追问。要点（解释口径，非代码问题）：
- 手机端只是遥控端，**真正执行在电脑端**；会话被取消时云端会给电脑端发终止指令 → 这就是「电脑端已同步终止运行」。

- 与工具层的 `rm -rf` 空返回是**两个不同层面**：前者平台取消 run，后者安全策略静默拦截；叠加起来体感就是「任务总中断」。
- 缓解：长任务别中途插话/切模式；优先在电脑端跑；关键状态落 `.workbuddy/memory/`，断了能续。

### 派息日历 1/2/3 月为 0 的根因（同日 16:00 诊断）
用户质疑 QQQM/CGDV/VOO 季度派息、TLT 月度派息，为何 1–3 月是 0。

```js
const seed = row.code.charCodeAt(0) + row.code.length;
const month = 4 + (seed % 5);        // 只会落在 4–8 月
buckets[(month + 2) % 12]            // 派生月也只到 6–10 月
```
